pyGameMath / gem
================

Pure-Python mathematics for games and graphics. The distribution name and
import namespace are ``gem``. Current build metadata and the package description
use README.md; this file remains as a historical documentation entry point.

See README.md and docs/getting-started/installation.md for installation, and
docs/development/packaging.md for build, version and compatibility policy.
The historical PyPI 0.1.12 release does not contain the current implementation.
